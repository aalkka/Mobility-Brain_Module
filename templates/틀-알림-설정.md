# 알림 설정

> 폰이 무엇을 언제 울릴지 정하는 표(mobility 모듈). 아래 json 블록을 고치면(PC 옵시디언 · 폰 · 대화로 Claude 에게) 폰이 다음에 당겨 올 때 반영된다. 재시작은 필요 없다.
> 값이 틀리면 그 칸만 기본값으로 울리고, 폰에 «알림 설정 틀림» 이 한 번 뜬다. 점검 = 행위 «알림 설정 점검» · `py -3 .claude/skills/mobility/scripts/alarms.py --check`.
> 처음 값은 «모바일 연결 설정»(스킬 mobility:setup)이 물어서 채웠다.

```json
{
 "켬": true,
 "기본": {"며칠_전": [3, 1], "시각": ["20:00"]},
 "파일": {},
 "과목": {},
 "글자": [],
 "잘_시간": {"켬": true, "부터": "23:00", "까지": "08:00"},
 "바로": {"막힘": true, "옮겨짐": true, "늦게_앎": true, "새_공지": true},
 "당겨_오기_분": 30
}
```

## 칸

| 칸 | 뜻 | 예 |
|---|---|---|
| `켬` | `false` 면 전부 끈다. 폰도 다음 당기기에 예약을 지운다 | `"켬": false` |
| `기본` | 모든 줄의 규칙. 며칠 전 × 시각 만큼 울린다 | `{"며칠_전": [7, 3, 1], "시각": ["09:00", "20:00"]}` = 6번 |
| `파일` | 울릴 일정 파일(일정 폴더 안 이름). 여기 없는 파일은 안 울린다. 파일마다 규칙을 줄 수 있다. `"*"` = 일정 폴더의 모든 파일 | `"학사일정.md": {"며칠_전": [1], "시각": ["10:00"]}` |
| `과목` | 줄 머리(첫 ` · ` 앞)가 같은 줄의 규칙 | `"물리": {"며칠_전": [2]}` |
| `글자` | 이 글자가 든 줄만 다르게. 위에서 아래로 덮는다 | `{"포함": "기말고사", "며칠_전": [14, 7, 3, 1]}` · `{"포함": "면담", "끔": true}` |
| `잘_시간` | **방해 금지(잘 시간)**. 이때 떨어진 울림은 끝나는 시각으로 미룬다(급함은 그대로). `켬` 이 `false` 면 끈다 — 시각은 남겨 두고 켬 한 칸만 바꾸면 된다. 없으면 켬 · 부터와 까지가 같아도 없음 | `{"켬": true, "부터": "00:00", "까지": "07:00"}` · 끔 `{"켬": false, "부터": "23:00", "까지": "08:00"}` |
| `바로` | 시각 예약 없이 폰이 당겨 올 때 울리는 것 | 아래 |
| `당겨_오기_분` | 폰이 몇 분마다 깨어 PC 에 물어보나(15~1440). 짧을수록 «바로»가 빨라지고 배터리를 더 쓴다 | `"당겨_오기_분": 45` |

규칙 안에 쓰는 칸은 `며칠_전`(0 = 그날) · `시각` · `끔` 셋이다. 덮는 순서는 기본 ← 파일 ← 과목 ← 글자다.

## 바로 알릴 것

| 칸 | 언제 |
|---|---|
| `막힘` | 수집이 막혀 사람 손이 필요할 때(로그인 끊김 등 · 수집-대기열의 사람 줄) |
| `옮겨짐` | 이미 있던 일정의 날짜가 바뀌었을 때 |
| `늦게_앎` | 첫 울림 시각을 이미 지나 처음 알게 된 일정(1일 전은 그대로 울린다) |
| `새_공지` | 판정을 통과해 볼트에 든 새 공지. 한 공지는 한 번만 울린다. 게시 7일이 넘은 글은 안 울리고, 한 번에 넷 이상이면 «새 공지 N건» 하나로 묶는다 |

«바로»는 폰이 당겨 올 때 울리므로 몇 분에서 수십 분 걸린다. 진짜 즉시는 아니다.

## 안 되게 해 둔 것

- 규칙의 시각이 모두 마감 뒤면 마감 한 시간 전에 울린다. 규칙 때문에 한 번도 안 울리는 줄은 없다.
- 이 표가 깨지면(json 오류 · `파일` 을 비움 · 없는 이름만 적음) 마지막으로 맞았던 `파일` 로 울리고 알린다. 맞았던 적이 없으면 일정 폴더의 모든 파일로 울린다. 다 끄려면 `켬` 을 쓴다.
- 일정 하나만 다르게: 캘린더 줄의 종 → 그 일정만 이 표에서 벗어난다. 저장 = [[일정별-알림]].
